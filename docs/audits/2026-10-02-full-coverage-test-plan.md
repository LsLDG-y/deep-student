## 二、宣传的 13 项能力 → 必测闭环

1. **AI 对话学习**：附件（图片 / PDF）提问、知识库检索 + 引用回原文、技能（讲解 / 出题 / 制卡 / 导图）
2. **学习资源中心**：上传各格式 → 解析 / OCR → 索引 → 预览；文件夹、搜索、标签、收藏
3. **思维导图**：从笔记 / 对话生成 → 导图 ⇄ 大纲 → 编辑 → 背诵模式 → 引用定位节点
4. **题目集与练习**：OCR 导入 / AI 出题 → 练习（每日 / 限时 / 模拟）→ 批改 → 错题 → 复习计划 → 掌握度
5. **Anki 智能闪卡**：资料 / 笔记 / 划词 / 对话制卡 → 模板 → 任务台 → 自动入队 → 复习 → 导出 APKG / AnkiConnect
6. **PDF / DOCX 阅读**：阅读、目录、搜索、划词动作（问 AI / 翻译 / 制卡 / 存笔记 / 批注）、关联对话
7. **翻译工作台**：领域预设、整篇 / 段落翻译、精读
8. **作文批改**：多场景批改 → 标注 → 采纳修改 → 存笔记 / 制卡 / 入错题本
9. **深度研究**：多引擎搜索 → 报告
10. **学术检索**：arXiv 等检索 → 收录
11. **智能记忆**：对话中记住偏好 / 事实 → 后续对话使用
12. **技能系统 / MCP**：技能管理、启用 / 禁用
13. **本地优先 / 数据治理**：备份 / 恢复、导入导出

另：今日学习 / 周报 / 待办 + 番茄钟 / 设置 / 移动端布局 / 工作台模式。

## 三、每一步都要检查的 UI / UX / 视觉点

- 入口是否可发现（侧栏 / 首页 / 右键 / 划词菜单）、步骤是否少而顺、空态与引导
- 加载 / 进度 / 失败的反馈与可恢复性；长任务是否可离开再回来
- 窄面板 / 分栏 / 移动断点下的排版（挤压、截断、竖排、溢出）
- 字体层级、间距、对齐、颜色一致性、暗色模式
- 中英混排、公式、代码、表格、图片在各处（对话 / 笔记 / 卡片 / 预览）的渲染
